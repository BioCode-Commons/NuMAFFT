# Benchmark data

`bash bench/get_data.sh` fetches the precursor project's `data-v1` release and checks
the files against `DATA_MD5.txt`. The local run manifests also record SHA-256 values.
The source release remains at https://github.com/yih0nk/fast-mafft/releases/tag/data-v1.

## Inputs used in the local comparison

| File under `bench/data/` | Sequences | Kind and source |
| :--- | ---: | :--- |
| `rnasim579.fa` | 579 | Simulated RNA; RNASim sample distributed by TWILIGHT |
| `rnasim2k.fa` | 2,000 | Simulated RNA; fixed subset of RNASim 10K |
| `prot2k.fa` | 2,000 | Protein sequences generated by `simulate_protein.py` |
| `large/homfam_sdr_sub3k.fa` | 3,000 | Biological protein-family data; fixed HomFam SDR subset |
| `large/16S.T.fa` | 7,350 | Biological 16S rRNA sequences, with alignment gaps removed |

RNASim was simulated by Guo, Wang and Kim. RNASim, HomFam and the 16S inputs were
distributed with Smirnov's Recursive MAGUS datasets on Illinois Data Bank,
https://doi.org/10.13012/B2IDB-1048258_V1, under CC0. HomFam originated from the
Clustal Omega benchmark families. The RNASim sample from TurakhiaLab/TWILIGHT carries
the notice retained in [THIRD_PARTY_NOTICES.md](biocode/THIRD_PARTY_NOTICES.md).

The input hashes, lengths, commands and output comparisons are in each
`biocode/results/*/manifest.json` and `runs.jsonl`. RNASim and prot2k are simulated;
they should not be described as empirical biological samples.

## Historical and optional inputs

The same release contains the larger RNASim, 16S and HomFam inputs used by the original
32-core CARC jobs. Their source groups and filenames are recorded by the checksum
manifest and retained job logs. Synthetic DNA and protein inputs were generated by
`simulate.py` and `simulate_protein.py` in the precursor repository.

`bash bench/get_data.sh --long` fetches the separate `data-long-v1` release and checks
`DATA_MD5_LONG.txt`. These include simulated long sequences and NCBI SARS-CoV-2
genomes. The 2,000-genome case has a documented multithread output difference;
it was not included in the local comparison. The original versioned accessions are
retained in FASTA headers. Source release:
https://github.com/yih0nk/fast-mafft/releases/tag/data-long-v1.

BAliBASE was used in the precursor project's validation. It is not redistributed
here and was not rerun for this local test.
