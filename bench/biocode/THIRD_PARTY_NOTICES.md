# Benchmark data and output notices

The code and documentation retain the repository's BSD license and its MAFFT/fast-mafft
copyright notices. This file records the data notices for the aligned outputs retained here.
Full input provenance is in `bench/DATA.md` in the source repository.

- `rnasim579`: RNASim RNA simulation sample distributed by TurakhiaLab/TWILIGHT. Its repository
  identifies the MIT license; the notice is reproduced below. Source:
  https://github.com/TurakhiaLab/TWILIGHT/blob/main/LICENSE
- `rnasim2k`: simulated RNASim subset from the Recursive MAGUS archive, released under CC0.
- `homfam_sdr_sub3k` and `16S.T`: HomFam protein-family and 16S rRNA inputs from the Recursive
  MAGUS archive, released under CC0. Archive DOI: https://doi.org/10.13012/B2IDB-1048258_V1
- `prot2k`: synthetic protein data generated by the source repository's `bench/simulate_protein.py`.
